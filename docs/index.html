Textbook BM25 idf goes negative

The published idf falls below zero once a term appears in more than half the collection — the score then subtracts. Lucene's 1 + … floors it above zero. Measured on this corpus:

formvalue for document (df=10/12)
ln((N − df + 0.5) / (df + 0.5))−1.4351
ln(1 + (N − df + 0.5) / (df + 0.5))+0.2136

This page uses the Lucene form. Set k1=0 to flatten saturation, b=0 to switch length normalisation off — both are live above.
